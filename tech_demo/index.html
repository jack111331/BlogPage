Overview

This project aims to build a universal, real-time render data extraction pipeline on modern game engines. Instead of integrating with each engine separately, it works at the graphics API level, so games built on very different engines share a single extraction path. The data it collects is intended for large-scale AI model training.

01

Engine-agnostic

One Graphics API Proxy sits between the engine and D3D12, covering Messiah, Snowdrop, Anvil, BlackSpace, RAGE and Unreal titles.

02

Real-time

Data is copied every frame while the game runs, at a cost of tens of microseconds per frame.

03

Training-ready signals

Camera pose, metric depth, and object geometric and material information, captured together for each frame.

How the demo is recorded

The game execution environment and the visualization environment are kept separate. The pipeline sends the extracted data to Blender over UDP, and Blender renders the camera trajectory. Because UDP gives no delivery guarantees, some latency and packet loss in the trajectory view is expected.

Architecture

Every engine renders through the same graphics API. The Graphics API Proxy intercepts those calls, forwards them to D3D12, and uses D3D12 to retrieve the camera, metric depth, and object geometric and material information.
